# Café Shop

Landing page de uma cafeteria, desenvolvida com HTML, CSS e JavaScript. O projeto apresenta a identidade visual do estabelecimento, seu menu e seções para avaliações e reservas, com foco em uma navegação responsiva.

## Demonstração

Acesse a versão publicada: [Coffee shop](https://wwilliamsantana.github.io/coffee-shop/)

## Funcionalidades

- Apresentação da cafeteria.
- Seção sobre o estabelecimento.
- Exibição do menu.
- Área de avaliações.
- Seção de reservas.
- Layout responsivo para diferentes tamanhos de tela.
- Animações utilizando CSS Keyframes.

## Tecnologias

- HTML5
- CSS3
- JavaScript
